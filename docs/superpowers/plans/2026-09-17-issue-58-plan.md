## Before you start

### What this change is, in four sentences

`FontDecompressor` keeps four "page slots", each holding the decompressed glyph
bitmaps of one font for one screenful of text. `FontCacheManager::PrewarmScope`
frees them around every reader render, but `textsettings::renderPreview` prewarms
outside any scope and never frees, so four changes on the Text-settings screen
exhaust the cap and every later change logs `[ERR] [FDC] All 4 page buffer slots
full`. Four slots is the right number — only the eight compressed Noto reading
families can take one, and only one of them is on screen at a time — so this
change fixes the caller, tells the truth in the constant's comment, makes the
refusal say which font it refused, and adds a dedupe guard.

### Two build facts that will bite you

1. **`.c` files must stay `.c`.** `lib/uzlib/src/tinflate.c` does not compile as
   C++ — `tinflate.c:559` assigns a `void*` to an `unsigned char*`, which is
   legal C and an error in C++. `test/CMakeLists.txt:2` declares
   `project(crosspoint_reader_tests C CXX)`, so CMake compiles `.c` with the C
   compiler automatically. Do not rename `UzlibChecksumStubs.c` to `.cpp`.
2. **The font-header fixtures warn under `-Wextra`.**
   `crosspoint_test_common` adds `-Wall -Wextra -pedantic`
   (`test/CMakeLists.txt:42-47`) and the generated font headers leave
   `glyphMissHandler` uninitialised, so every one emits
   `missing field 'glyphMissHandler' initializer`. There is no `-Werror`, so
   these are noise, not failures — the suite's `CMakeLists.txt` in step 1
   suppresses that one warning locally and says why.

## Step 3 — One slot per distinct font (RED: two slots, bytes double)

Today a second `prewarmCache` for a font already resident allocates a **second**
slot that `getBitmap` can never reach: it `break`s after the first slot matching
`fontData` (`FontDecompressor.cpp:173`). So deduping removes an allocation and
changes no rendered pixel.

### 3a. RED — append to `test/font_page_slots/FontPageSlotsTest.cpp`

```cpp
TEST(FontPageSlots, OneSlotPerDistinctFontData) {
  FontDecompressor decompressor;

  ASSERT_EQ(decompressor.prewarmCache(&notoserif_12_regular, SAMPLE), 0);
  ASSERT_EQ(decompressor.usedPageSlots(), 1);

  // getBitmap() breaks after the first slot matching fontData
  // (FontDecompressor.cpp:173), so a second slot for the same font is dead
  // weight: unreachable, and its glyphs fall through to the hot group anyway.
  EXPECT_EQ(decompressor.prewarmCache(&notoserif_12_regular, SAMPLE), 0);
  EXPECT_EQ(decompressor.usedPageSlots(), 1);
}

TEST(FontPageSlots, AlreadyWarmDoesNotReallocate) {
  FontDecompressor decompressor;

  ASSERT_EQ(decompressor.prewarmCache(&notoserif_12_regular, SAMPLE), 0);
  const uint32_t bytesAfterFirst = decompressor.getStats().pageBufferBytes;
  ASSERT_GT(bytesAfterFirst, 0u);

  decompressor.prewarmCache(&notoserif_12_regular, SAMPLE);

  // Asserted as a relation, not an absolute: regenerating a font header would
  // change the byte count but must never make a repeat call allocate again.
  EXPECT_EQ(decompressor.getStats().pageBufferBytes, bytesAfterFirst);
}
```

## Step 4 — Pin the cap and the refusal sentinel (guard, green on arrival)

No production change. These two cases fix the meaning of the constant in place,

### 4a. Append to `test/font_page_slots/FontPageSlotsTest.cpp`

```cpp
TEST(FontPageSlots, SlotsFullIsVisibleToTheCaller) {
  FontDecompressor decompressor;

  // Distinct addresses, identical content — all pointer-keyed accounting sees.
  EpdFontData fonts[FontDecompressor::MAX_PAGE_SLOTS + 1];
  for (auto& font : fonts) font = notoserif_12_regular;

  for (uint8_t i = 0; i < FontDecompressor::MAX_PAGE_SLOTS; i++) {
    EXPECT_EQ(decompressor.prewarmCache(&fonts[i], SAMPLE), 0) << "slot " << int{i};
  }
  ASSERT_EQ(decompressor.usedPageSlots(), FontDecompressor::MAX_PAGE_SLOTS);

  // The cap check is before the increment (FontDecompressor.cpp:255), so the
  // last slot allocates and only the one past it is refused. -1 is the
  // slots-full sentinel; nothing is allocated and no slot is consumed.
  EXPECT_LT(decompressor.prewarmCache(&fonts[FontDecompressor::MAX_PAGE_SLOTS], SAMPLE), 0);
  EXPECT_EQ(decompressor.usedPageSlots(), FontDecompressor::MAX_PAGE_SLOTS);
}

TEST(FontPageSlots, TheCapCoversOneFamilysFourStyles) {
  // Why four is enough: only the eight compressed Noto reading families take a
  // slot, the status bar and UI fonts are uncompressed, SD fonts take the
  // SdCardFont path, and one reading family is on screen at a time. So the
  // ceiling is one family's four styles. If a second compressed family is ever
  // drawn on one screen this stops being true — and FontCacheManager will log
  // which font it refused.
  static_assert(FontDecompressor::MAX_PAGE_SLOTS >= 4,
                "one reading family's R/B/I/BI must fit simultaneously");
  EXPECT_GE(FontDecompressor::MAX_PAGE_SLOTS, 4);
}
```

## Step 5 — `releaseBuiltinGlyphCache()` (RED: does not compile)

The preview needs to drop its built-in page slots **without** touching the SD
glyph cache. `FontCacheManager::clearCache()` cannot be used: it also calls
`SdCardFont::clearCache()` on every loaded SD font, which advances the underuse
hysteresis and frees outright below the heap floor
(`lib/EpdFont/SdCardFont.cpp:116-147`) — and
`TextSettingsPreview.cpp:90-95` documents that its key-based reuse relies on
nothing evicting that cache while the screen is up.

### 5a. RED — append to `test/font_page_slots/FontPageSlotsTest.cpp`

```cpp

  owned.reserve(std::size(fonts));
  for (size_t i = 0; i < std::size(fonts); i++) {
    owned.emplace_back(&fonts[i]);
```
