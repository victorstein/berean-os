This plan adds two host tests to `test/persistable_store/PersistableStoreTest.cpp`. They cover a
refused future-version file, and a garbage file, arriving through `.tmp` adoption on the
`PersistableStore<T>` path. Nothing outside test code changes.

- Spec: `docs/superpowers/specs/2026-09-26-issue-133-design.md`. Assumptions A-1 to A-10 and
  mutations M1 to M4 below refer to it.
- Research: `docs/superpowers/research/2026-09-26-issue-133-research.md`.
- Modelled on the same file's `ARefusedLoadBlocksEverySaveAndLeavesTheFileUntouched` (`:62-73`)
  and `AMissingFileLiftsTheRefusal` (`:75-84`).

FILES: test/persistable_store/PersistableStoreTest.cpp

The mutation steps temporarily edit `lib/Serialization/FormatVersion.h`,
`lib/Serialization/PersistableStore.cpp` and `lib/Serialization/TempAdoption.h`. They are
deliberately not declared above. Each edit is reverted within the same step with
`git checkout -- <file>`, so none is ever committed. The rule for every step: **a step does not
end while `git status --short` lists any `lib/` file.**

**6b.** Append at the end of the file, after test 1:

```cpp
TEST_F(PersistableStoreGuard, AGarbageTempIsKeptByTheLoadAndStillLiftsTheRefusal) {
  // Start refused: from a clear flag, a load that wrongly reported the .tmp's
  // ParseError would keep the flag clear and this save would pass anyway.
  storage_fake::putFile(PATH, NEWER);
  ASSERT_FALSE(store().loadFromFile());
  ASSERT_TRUE(Storage.remove(PATH.c_str()));
  storage_fake::putFile(TMP_PATH, TORN);

  EXPECT_FALSE(store().loadFromFile()) << "Missing";
  EXPECT_EQ(bytesOn(TMP_PATH), TORN) << "an unusable .tmp stays on the card";
  EXPECT_EQ(bytesOn(PATH), "<absent>");

  store().value = 9;
  EXPECT_TRUE(store().saveToFileAtomic());
  EXPECT_EQ(bytesOn(PATH), R"({"v":1,"value":9})");
  EXPECT_EQ(bytesOn(TMP_PATH), "<absent>") << "the save replaced the torn .tmp";
}
```
