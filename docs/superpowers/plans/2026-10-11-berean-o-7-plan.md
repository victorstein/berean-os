# R22: keep Home's verse across deep sleep — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** on a wake with the same day, the same `bible.json` size and the same firmware build,
Home restores its saved verse and paints once, with no `Verse scan` and no second paint.

**Architecture:** the work splits into three units.

- **`HomeVerseDoc`** is the pure JSON format of `/.berean/home-verse.json`: version, build
  identity, key, empty reason, the pick with its fitted lines, and a derived byte budget.
- **`HomeVerseFile`** reads and writes that file through `PersistableStoreBase`'s atomic and
  adopting helpers. It needs no renderer, so it is host-tested against the in-memory storage fake.
- **`HomeVerse`**, the existing singleton, restores the file once per boot and saves after every
  completed scan. `LauncherActivity` is untouched: `isCurrent()` returning true is what removes the
  scan and the second paint.

**Tech stack:** C++20 (GNU), ArduinoJson 7.4.2, ESP-IDF 5.5.2 through pioarduino 55.03.37,
googletest 1.17 on the host, CMake.

**Spec:** `docs/superpowers/specs/2026-10-11-berean-o-7-design.md`. Read its assumptions A1–A15
before Task 1. Every task below cites the assumption it implements.

## Deviations from the spec's sketch, decided here

The spec says "the plan names the details". These are the details.

1. **`buildId` is `const char*`, not `std::string_view`.** Every caller holds a NUL-terminated
   buffer. A `const char*` also goes into ArduinoJson and `strcmp` without the `string_view`
   null-termination pitfall (CLAUDE.md, "`std::string_view` and null termination").
2. **`HomeVerseFile::Load` gains `NoBuildId`.** It is the "unusable build identity" row of the
   spec's error table, as a value `HomeVerse` can log once.
3. **`HomeVerseFile::save` returns the bytes written, or 0 when nothing was written.** The size
   goes into the `Verse saved` log line, and a JSON document is never 0 bytes.
4. **The layout pin compares only the width and height of `verseText`.** The spec's testing list
   said "(x, y, width, height)", but `y` legitimately moves with the theme: the hero heights are
   250 and 272 (`test/home_layout/HomeLayoutTest.cpp:63-66`). Only width and height decide the
   fit. The spec line is corrected in the same commit as this plan.
5. **The two identities are logged on their own line, not on the restore line.** The spec's
   Logging section puts `file 1a2b3c4d, running 5e6f7a8b` on `Verse restore: other build`. Instead,
   `HomeVerseFile::load` logs `[HOMEV] Home verse file is from build <file>; running <ours>` just
   before the restore line. That keeps `fromJson`'s document inside `HomeVerseFile`, instead of
   handing it back to `HomeVerse`. The device run still sees both identities, one line earlier.

#pragma once

#include <ArduinoJson.h>

#include <cstddef>
#include <cstdint>

#include "activities/launcher/HomeVerseCache.h"

// Format rules for /.berean/home-verse.json: Home's last completed verse scan, kept so a wake on
// the same day, file and build skips it. A cache, not study data: losing it costs one scan. No
// storage access -- HomeVerseFile is the shell -- and free of <Arduino.h> so test/home_layout runs
// it on the host. Never measures or serialises, as PlacesDoc.
namespace HomeVerseDoc {

inline constexpr int FORMAT_VERSION = 1;

// Room for a whole hex SHA-256; the firmware stores its first 8 digits.
inline constexpr size_t MAX_BUILD_ID_BYTES = 64;

enum class Restore : uint8_t { Restored, UnknownFormat, OtherBuild, Malformed };

// An all-zero identity is an image whose SHA was never filled in, which would make every build
// look the same.
bool isUsableBuildId(const char* buildId);

// `entry` must be valid.
void toJson(const home_verse::Entry& entry, const char* buildId, JsonDocument& doc);

// Fills `out` in place, since an Entry is too large for the stack. `out.valid` is true only on
// Restored: any field of the wrong type or out of range refuses the whole entry. `rungCount`
// bounds the stored font rung.
Restore fromJson(JsonVariantConst doc, const char* buildId, uint8_t rungCount, home_verse::Entry& out);

}  // namespace HomeVerseDoc
```

#include "activities/launcher/HomeVerseDoc.h"

#include <StudyStore/Unit.h>

#include <cstring>

namespace HomeVerseDoc {
namespace {

// The on-card codes, kept apart from home_verse::Empty's underlying values so that reordering the
// enum cannot change what a saved file means.
constexpr uint8_t EMPTY_CODE_PICK = 0;
constexpr uint8_t EMPTY_CODE_NO_PASSAGES = 1;
constexpr uint8_t EMPTY_CODE_TOO_LONG = 2;

uint8_t emptyCode(const home_verse::Empty empty) {
  switch (empty) {
    case home_verse::Empty::None:
      return EMPTY_CODE_PICK;
    case home_verse::Empty::NoPassages:
      return EMPTY_CODE_NO_PASSAGES;
    case home_verse::Empty::TooLong:
      return EMPTY_CODE_TOO_LONG;
  }
  return EMPTY_CODE_NO_PASSAGES;
}

}  // namespace

bool isUsableBuildId(const char* const buildId) {
  if (buildId == nullptr) return false;
  const size_t length = strnlen(buildId, MAX_BUILD_ID_BYTES + 1);
  if (length == 0 || length > MAX_BUILD_ID_BYTES) return false;
  return strspn(buildId, "0") != length;
}

void toJson(const home_verse::Entry& entry, const char* const buildId, JsonDocument& doc) {
  doc["v"] = FORMAT_VERSION;
  doc["b"] = buildId;

  const JsonObject key = doc["k"].to<JsonObject>();
  key["dt"] = entry.key.dated;
  key["y"] = entry.key.dated ? entry.key.day.year : 0;
  key["m"] = entry.key.dated ? entry.key.day.month : 0;
  key["d"] = entry.key.dated ? entry.key.day.day : 0;
  key["f"] = entry.key.fileExists;
  key["n"] = entry.key.fileBytes;

  doc["e"] = emptyCode(entry.empty);
  if (!entry.hasPick) return;

  const JsonObject pick = doc["p"].to<JsonObject>();
  pick["u"] = study::unitToCompact(entry.pick.start);
  pick["s"] = entry.pick.spine;
  // Cast: a char array would be stored as a fixed-length literal, garbage after the NUL included.
  pick["r"] = static_cast<const char*>(entry.pick.reference);
  pick["rung"] = entry.pick.rung;
  const JsonArray lines = pick["l"].to<JsonArray>();
  for (uint8_t i = 0; i < entry.pick.lineCount; ++i) lines.add(entry.pick.line(i));
}

}  // namespace HomeVerseDoc
```

// is<T>() before every read: a `| default` read takes a wrong type silently, and most of these
// defaults are themselves valid values. ArduinoJson's is<T>() on an integer type also checks range.
bool readKey(const JsonVariantConst json, home_verse::Key& key) {
  if (!json.is<JsonObjectConst>()) return false;
  if (!json["dt"].is<bool>() || !json["f"].is<bool>() || !json["y"].is<uint16_t>() || !json["m"].is<uint8_t>() ||
      !json["d"].is<uint8_t>() || !json["n"].is<uint32_t>()) {
    return false;
  }
  key.dated = json["dt"].as<bool>();
  key.day.year = json["y"].as<uint16_t>();
  key.day.month = json["m"].as<uint8_t>();
  key.day.day = json["d"].as<uint8_t>();
  key.fileExists = json["f"].as<bool>();
  key.fileBytes = json["n"].as<uint32_t>();
  return !key.dated || isValidCivilDate(key.day);
}

bool readPick(const JsonVariantConst json, const uint8_t rungCount, home_verse::Pick& pick) {
  if (!json.is<JsonObjectConst>()) return false;
  if (!json["u"].is<const char*>() || !json["s"].is<uint16_t>() || !json["r"].is<const char*>() ||
      !json["rung"].is<uint8_t>() || !json["l"].is<JsonArrayConst>()) {
    return false;
  }

  const std::optional<study::Unit> start = study::unitFromCompact(std::string(json["u"].as<const char*>()));
  if (!start) return false;
  const char* const reference = json["r"].as<const char*>();
  const size_t referenceBytes = strlen(reference);
  if (referenceBytes >= home_verse::REFERENCE_BYTES) return false;
  const uint8_t rung = json["rung"].as<uint8_t>();
  if (rung >= rungCount) return false;

  const JsonArrayConst storedLines = json["l"].as<JsonArrayConst>();
  if (storedLines.size() == 0 || storedLines.size() > home_verse::MAX_LINES) return false;
  std::vector<std::string> lines;
  lines.reserve(storedLines.size());
  for (const JsonVariantConst line : storedLines) {
    if (!line.is<const char*>()) return false;
    lines.emplace_back(line.as<const char*>());
  }
  if (!home_verse::packLines(lines, pick)) return false;

  pick.start = *start;
  pick.spine = json["s"].as<uint16_t>();
  pick.rung = rung;
  memcpy(pick.reference, reference, referenceBytes + 1);
  return true;
}

}  // namespace

bool isUsableBuildId(const char* const buildId) {
  if (buildId == nullptr) return false;
  const size_t length = strnlen(buildId, MAX_BUILD_ID_BYTES + 1);
  if (length == 0 || length > MAX_BUILD_ID_BYTES) return false;
  return strspn(buildId, "0") != length;
}

void toJson(const home_verse::Entry& entry, const char* const buildId, JsonDocument& doc) {
  doc["v"] = FORMAT_VERSION;
  doc["b"] = buildId;

  const JsonObject key = doc["k"].to<JsonObject>();
  key["dt"] = entry.key.dated;
  key["y"] = entry.key.dated ? entry.key.day.year : 0;
  key["m"] = entry.key.dated ? entry.key.day.month : 0;
  key["d"] = entry.key.dated ? entry.key.day.day : 0;
  key["f"] = entry.key.fileExists;
  key["n"] = entry.key.fileBytes;

  doc["e"] = emptyCode(entry.empty);
  if (!entry.hasPick) return;

  const JsonObject pick = doc["p"].to<JsonObject>();
  pick["u"] = study::unitToCompact(entry.pick.start);
  pick["s"] = entry.pick.spine;
  // Cast: a char array would be stored as a fixed-length literal, garbage after the NUL included.
  pick["r"] = static_cast<const char*>(entry.pick.reference);
  pick["rung"] = entry.pick.rung;
  const JsonArray lines = pick["l"].to<JsonArray>();
  for (uint8_t i = 0; i < entry.pick.lineCount; ++i) lines.add(entry.pick.line(i));
}

Restore fromJson(const JsonVariantConst doc, const char* const buildId, const uint8_t rungCount,
                 home_verse::Entry& out) {
  out.valid = false;
  if (!persist::isKnownFormatVersion(doc["v"] | 0, FORMAT_VERSION)) return Restore::UnknownFormat;
  if (!doc["b"].is<const char*>() || strcmp(doc["b"].as<const char*>(), buildId) != 0) return Restore::OtherBuild;

  if (!readKey(doc["k"], out.key)) return Restore::Malformed;
  if (!doc["e"].is<uint8_t>()) return Restore::Malformed;
  const std::optional<home_verse::Empty> empty = emptyFromCode(doc["e"].as<uint8_t>());
  if (!empty) return Restore::Malformed;

  const bool hasPick = *empty == home_verse::Empty::None;
  // HomeVerse::scan scans only when the file exists, so a pick from a missing file is corrupt.
  if (hasPick && !out.key.fileExists) return Restore::Malformed;
  if (hasPick == doc["p"].isNull()) return Restore::Malformed;
  if (hasPick && !readPick(doc["p"], rungCount, out.pick)) return Restore::Malformed;

  out.empty = *empty;
  out.hasPick = hasPick;
  out.valid = true;
  return Restore::Restored;
}

}  // namespace HomeVerseDoc

inline constexpr size_t DOC_WRAPPER_BYTES = 106;
static_assert(FORMAT_VERSION < 10, "DOC_WRAPPER_BYTES counts a one-digit version");
// 65535, 255, 255, 4294967295: the key's year, month, day and size at their types' maximum.
inline constexpr size_t MAX_KEY_NUMBER_BYTES = 5 + 3 + 3 + 10;
inline constexpr size_t MAX_EMPTY_CODE_BYTES = 1;

inline constexpr size_t MAX_UNIT_BYTES = 28;
// \u00XX is the longest escape JSON has, so every string byte is counted at six.
inline constexpr size_t ESCAPE_FACTOR = 6;
// Each line's two quotes, and the commas between lines.
inline constexpr size_t LINE_FRAMING_BYTES = 2 * home_verse::MAX_LINES + (home_verse::MAX_LINES - 1);

constexpr size_t worstCaseBytes() {
  return DOC_WRAPPER_BYTES + ESCAPE_FACTOR * MAX_BUILD_ID_BYTES + MAX_KEY_NUMBER_BYTES + MAX_EMPTY_CODE_BYTES +
         MAX_UNIT_BYTES + MAX_SPINE_BYTES + ESCAPE_FACTOR * (home_verse::REFERENCE_BYTES - 1) + MAX_RUNG_BYTES +
         LINE_FRAMING_BYTES + ESCAPE_FACTOR * home_verse::LINE_BUFFER_BYTES;
}

#include <Logging.h>
#include <PersistableStore.h>
#include <SaveBudget.h>
#include <SdPaths.h>

#include "activities/launcher/HomeVerseDoc.h"

namespace HomeVerseFile {
namespace {

constexpr const char* MODULE = "HOMEV";

// JsonDocument has no null allocator: the host suite passes nullptr for ArduinoJson's default.
JsonDocument makeDocument(ArduinoJson::Allocator* const allocator) {
  return allocator != nullptr ? JsonDocument(allocator) : JsonDocument();
}

}  // namespace

Load load(const char* const buildId, const uint8_t rungCount, ArduinoJson::Allocator* const allocator,
          home_verse::Entry& out) {
  out.valid = false;
  if (!HomeVerseDoc::isUsableBuildId(buildId)) return Load::NoBuildId;

  JsonDocument doc = makeDocument(allocator);
  const DocReadStatus status = PersistableStoreBase::readDocFromFileAdopting(sdpaths::HOME_VERSE_FILE, doc);
  if (status == DocReadStatus::Missing) return Load::None;
  if (status != DocReadStatus::Ok) return Load::Unreadable;

  switch (HomeVerseDoc::fromJson(doc.as<JsonVariantConst>(), buildId, rungCount, out)) {
    case HomeVerseDoc::Restore::Restored:
      return Load::Restored;
    case HomeVerseDoc::Restore::UnknownFormat:
      LOG_ERR(MODULE, "Refusing a Home verse file of an unknown format");
      return Load::UnknownFormat;
    case HomeVerseDoc::Restore::OtherBuild:
      LOG_DBG(MODULE, "Home verse file is from build %s; running %s", doc["b"] | "?", buildId);
      return Load::OtherBuild;
    case HomeVerseDoc::Restore::Malformed:
      LOG_ERR(MODULE, "Home verse file is malformed");
      return Load::Malformed;
  }
  return Load::Malformed;
}

size_t save(const home_verse::Entry& entry, const char* const buildId, ArduinoJson::Allocator* const allocator) {
  if (!entry.valid || !HomeVerseDoc::isUsableBuildId(buildId)) return 0;

  JsonDocument doc = makeDocument(allocator);
  HomeVerseDoc::toJson(entry, buildId, doc);
  if (doc.overflowed()) {
    LOG_ERR(MODULE, "OOM: Home verse document");
    return 0;
  }
  const size_t bytes = measureJson(doc);
  if (!persist::fitsBudget(bytes, HomeVerseDoc::SAVE_BUDGET)) {
    LOG_ERR(MODULE, "Refusing to save the Home verse: %u bytes exceeds budget %u", static_cast<unsigned>(bytes),
            static_cast<unsigned>(HomeVerseDoc::SAVE_BUDGET));
    return 0;
  }
  return PersistableStoreBase::writeDocToFileAtomic(sdpaths::HOME_VERSE_FILE, doc) ? bytes : 0;
}

const char* describe(const Load outcome) {
  switch (outcome) {
    case Load::None:
      return "none";
    case Load::Restored:
      return "restored";
    case Load::Unreadable:
      return "unreadable";
    case Load::UnknownFormat:
      return "unknown format";
    case Load::OtherBuild:
      return "other build";
    case Load::Malformed:
      return "malformed";
    case Load::NoBuildId:
      return "no build id";
  }
  return "?";
}

}  // namespace HomeVerseFile

    return;

  LOG_DBG(MODULE, "Verse saved: %u bytes, %lu ms", static_cast<unsigned>(bytes), millis() - started);

bool HomeVerse::scan(const GfxRenderer& renderer, const int textWidth, const int textHeight,
                     const home_verse::Key& key) {
  uint32_t seed = home_verse::FALLBACK_SEED;
  if (key.dated) {
    seed = study_sleep::dailySeed(key.day);
  } else {
    LOG_DBG(MODULE, "No date on the clock; fallback seed %08lx", static_cast<unsigned long>(seed));
  }
  auto sampler = makeUniqueNoThrow<study_sleep::Sampler>(&study_sleep::splitmixDraw, &seed);
  if (!sampler) {
    LOG_ERR(MODULE, "OOM: verse sampler");
    entry.valid = false;
    entry.empty = home_verse::Empty::NoPassages;
    return false;
  }

  study_sleep::FitRung rungs[RUNG_COUNT];
  for (uint8_t rung = 0; rung < RUNG_COUNT; ++rung) {
    rungs[rung] = study_sleep::FitRung{rung, renderer.getLineHeight(FONT_IDS[rung]), textHeight};
  }
  study_passage_scan::FitGate gate;
  gate.measure = &measureCardText;
  gate.measureCtx = &renderer;
  gate.floor = rungs[RUNG_COUNT - 1];
  gate.width = textWidth;
  gate.prefilterBytes = home_verse::PREFILTER_BYTES;

  char path[PATH_BYTES];
  biblePassagesPath(path, sizeof(path));
  study_passage_scan::ScanTotals totals;
  const unsigned long started = millis();
  const bool picked = key.fileExists && study_passage_scan::pickFromFile(path, *sampler, gate, totals);
  LOG_INF(MODULE, "Verse scan: %u bytes, %u not whole, %u over prefilter, %u unfit, picked %d, %lu ms",
          static_cast<unsigned>(totals.bytesParsed), static_cast<unsigned>(totals.rowsNotWhole),
          static_cast<unsigned>(totals.rowsOverPrefilter), static_cast<unsigned>(totals.rowsUnfit), picked ? 1 : 0,
          millis() - started);
  if (totals.outOfMemory) {
    // Not cached, so the next Home entry retries.
    LOG_ERR(MODULE, "OOM: verse scan document");
    entry.valid = false;
    entry.empty = home_verse::Empty::NoPassages;
    return false;
  }

  // Filled in place: an Entry is over half a kilobyte, too large for the stack.
  entry.valid = true;
  entry.key = key;
  entry.hasPick = false;
  entry.empty = home_verse::emptyReason(totals.rowsUnfit, totals.rowsOverPrefilter);
  if (!picked) return true;

  const study_sleep::Candidate& candidate = *sampler->result();
  const auto fitted =
      study_sleep::fitPassage(candidate.text, rungs, RUNG_COUNT, textWidth, &measureCardText, &renderer);
  if (!fitted.fits || !home_verse::packLines(fitted.lines, entry.pick)) {

    // measurements disagreed. Never draw it cut.
    LOG_ERR(MODULE, "Picked verse does not fit the card; showing the hint");
    entry.empty = home_verse::Empty::TooLong;
    return true;
  }
  entry.pick.start = candidate.start;
  entry.pick.spine = candidate.spine;
  entry.pick.rung = fitted.rung;
  memcpy(entry.pick.reference, candidate.reference, sizeof(entry.pick.reference));
  entry.hasPick = true;
  entry.empty = home_verse::Empty::None;
  return true;
}

## `/.berean/home-verse.json`

Home's last completed verse scan. It lets a wake on the same day, with `bible.json` the same size
and the same firmware build, show the verse without scanning again. A cache, not study data:
deleting it costs one scan. Owned by `src/activities/launcher/HomeVerseDoc.{h,cpp}` (format,

### Version 1

- `v` — format version. Required: an absent, zero, negative or newer `v` is not restored. Home
  scans, and the save that follows replaces the file.

```json
{"v":1,"b":"1a2b3c4d","k":{"dt":true,"y":2026,"m":10,"d":11,"f":true,"n":43864},"e":0,
 "p":{"u":"v:43:3:16:0","s":1201,"r":"John 3:16","rung":1,"l":["For God loved the world","so much that he gave"]}}
```

- `b` — the build that wrote it: the first 8 hex digits of the firmware ELF's SHA-256. Another
  build's file is never restored, because its lines were fitted with that build's fonts.
- `k` — the key:
  - `dt` — whether the clock had a date;
  - `y`, `m`, `d` — the local date, 0 when undated;
  - `f` — whether `/.berean/passages/bible.json` existed;
  - `n` — its size in bytes.
- `e` — `0` a pick, `1` no whole passages, `2` passages too long for the card.
- `p` — present exactly when `e` is `0`:
  - `u` — the start unit as a compact `study::Unit`;
  - `s` — the spine hint;
  - `r` — the reference, ≤ 48 bytes;
  - `rung` — the font rung, 0–2;
  - `l` — the 1–4 lines, already fitted to the card.

A field of the wrong type or out of range refuses the whole file. The save budget, 3,943 bytes, is
derived from the caps (`HomeVerseDoc::worstCaseBytes()`).

## What this does

Every wake that lands on Home used to scan `/.berean/passages/bible.json` again (`Verse scan`,
405 ms on the owner's unit) and then paint Home a second time. Home's verse lived only in RAM,
and waking from deep sleep is a reset.

Home now saves its last completed scan to `/.berean/home-verse.json` and restores it once per boot.
On a wake with the same day, the same `bible.json` size and the same firmware build, Home paints
once, verse included, with no scan.

## Resources

- **Internal SRAM:** one `bool` on the static `HomeVerse` singleton. The resident cache is the
  existing static `Entry` (under 640 bytes, `HomeVerseCache.h:95`).
- **Heap:** transient only, freed before the paint.
  - Restore and save each build one JSON document of a few KB, in explicit PSRAM through
    `PsramJsonAllocator::json()`, as the passage scan does for passage text
    (`StudyPassageScan.cpp:115-118`).
  - `Storage.readFile` returns a `String` of the file's size, under 4 KB.
  - The restore copies the up-to-four fitted lines into `std::string`s for
    `home_verse::packLines`. That is transient, in internal SRAM (each block is under the 4,096-byte
    PSRAM routing threshold), at most about 530 bytes, once per boot.
  - No allocation is kept, and nothing allocates on the render path.
- **Stack:** a 9-byte build identity buffer.
- **Flash:** `<Flash line before>` → `<Flash line after>`. **RAM:** `<RAM line before>` →
  `<RAM line after>`.
- **SD:** one read of the file per boot that reaches Home with a Bible, and one atomic write per
  completed scan. There is never a write on a same-day wake.

## Storage discipline (CLAUDE.md)

1. **Atomic writes:** through `writeDocToFileAtomic`.
2. **Budget:** an explicit byte budget, 3,943 bytes derived from the format's caps, checked before
   every write, along with `doc.overflowed()`. The write is refused, never truncated.
3. **Read size:** the file is under 4 KB, far below `readFile`'s 50,000-byte cap.
4. **Format version:** `"v":1`. An unknown version is refused and rescanned, never reinterpreted.
5. **Owning task:** the loop task. `HalStorage` serialises every call.
